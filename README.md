# Rick and Morty Explorer 🛸

A clean and modern Android application that consumes the [Rick and Morty API](https://rickandmortyapi.com) to showcase characters, locations, and episodes from the show. Built with a focus on modern Android development practices.

## ✨ Key Features
* **Dynamic Character Feed**: Explore the multiverse with smooth scrolling.
* **Search & Filters**: Find characters by name.
* **Detailed Profiles**: View comprehensive info about each character.
* **Dark Mode Support**: Easy on the eyes for late-night binging.

## 🛠 Tech Stack
* **Language**: Kotlin
* **UI**: XML Layouts
* **Architecture**: MVVM
* **Networking**: Retrofit 2 & OkHttp
* **Image Loading**: Coil
* **DI**: Hilt
* **Concurrency**: Kotlin Coroutines & Flow
